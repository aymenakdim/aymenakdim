## 🚀 Featured Projects

### 🚗 Automotive ECU Network & Diagnostic Simulator
- Developing a modular C11 simulator for automotive ECUs communicating over a CAN bus.
- Implementing CAN frame encoding/decoding, sensor validation, and OBD-II diagnostic trouble codes.
- Preparing automated functional tests with Python and pytest.

### 🛣️ Traffic Sign Detection — ADAS
- Built a road-sign detection and recognition system using Raspberry Pi 4.
- Worked on camera capture, image preprocessing, classification, and real-world validation.

### 🧼 Smart Soap Dispenser — IoT
- Integrated sensors and actuators with a microcontroller and Firebase Realtime Database.
- Developed mobile and web supervision interfaces for device status and dispensing data.

### ⚙️ FPGA Simulation & RISC Processor
- Designed and simulated digital circuits using VHDL and Verilog.
- Worked on the design and simulation of a simplified RISC microprocessor.
